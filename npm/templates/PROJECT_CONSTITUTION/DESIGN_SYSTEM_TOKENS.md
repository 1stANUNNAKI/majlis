# 🎨 رموز نظام التصميم المعياري (Design System Tokens & HSL Palette)
- **الألوان الدلالية:** لوحة HSL ديناميكية تدعم الوضعين الداكن والفاتح بسلاسة متناهية.
- **التيبوغرافي:** دعم أصيل للخطوط العربية الراقية (Cairo, Tajawal, Outfit) مع ضبط تباعد الأسطر (Line-height) وأحجام القراءة المريحة.
- **الحركات الدقيقة (Micro-interactions):** استجابة فورية للأزرار والمؤشرات لإضفاء طابع حيوي وفخم.
