## 🌟 Overview · نظرة عامة

**MAJLIS (المجلس)** gives your AI coding assistant a real boss, an offensive security officer, an architectural arbitrator, and an uncompromising code reviewer.

Instead of a single AI model hallucinating self-approvals, **Majlis orchestrates 40 real specialized agents** divided into 6 strategic divisions. Every code release must pass through runnable verification contracts, an anti-sycophancy review panel, a zero-trust red gate, and a persistent chronological memory.

> [!NOTE]
> **No Hallucinated Passes:** In Majlis, "looks good to me" is forbidden. Nothing ships without real terminal execution proof (`verify: PASS`).

## 🚀 Quick Start Guide · دليل الاستخدام السريع

Follow these simple steps to run and integrate Majlis as a standalone repository on your machine:

### 1. Clone & Setup
Clone the repository and inspect the codebase:
```bash
git clone https://github.com/1stANUNNAKI/majlis.git
cd majlis
```

### 2. Deploy to Your IDE
Deploy the 40 agents, 91 skills, and governing commands directly into your editors:

| Goal | Command |
|---|---|
| **Deploy Everywhere (Recommended)** | `powershell -File install_system.ps1` *(or: `node npm/bin/install.js --all`)* |
| **Google Antigravity & Gemini CLI** | `node npm/bin/install.js --gemini` |
| **Claude Code** | `node npm/bin/install.js --claude` |
| **OpenCode** | `node npm/bin/install.js --opencode` |
| **Codex** | `node npm/bin/install.js --codex` |
| **Scaffold specific project (Cursor, VS Code, Windsurf)** | `node npm/bin/install.js --scaffold <path-to-your-project>` |

### 3. Run the Automated Pipeline
Run the autonomous end-to-end pipeline on any software directive:
```bash
node run.js "Build a modern responsive dashboard with auth and audit logging"
```
The orchestrator routes the task through the proper divisions, checks historical lessons in memory, coordinates agent execution, and runs the interactive QA validation loop.

### 4. The Adversarial War-Room (MARP)
Before making high-stakes, breaking, or critical architectural choices, invoke the **Majlis Adversarial Reasoning Protocol (MARP)**:
```bash
node run.js --deliberate "Design high-throughput banking ledger with zero-trust RBAC"
```
**What happens in the chamber:**
1. **The Domain Specialist:** Deconstructs the challenge from First Principles and calculates 2nd-order catastrophic effects.
2. **The Engineer:** Proposes the structural architecture.
3. **The Devil's Advocate:** Mandatorily rejects the initial draft and extracts at least one structural fatal flaw.
4. **The Pragmatic User:** Ruthlessly stress-tests usability and rejects artificial complexity.
5. **The Maestro:** Issues the pristine, final, unarguable implementation ready for execution.

### 5. Explore the 3D Interactive World
Majlis features a world-class 3D visualization running directly in your browser:
* Double-click **[`majlis_interactive_city.html`](majlis_interactive_city.html)** or serve it locally.
* **Features:** Built with **Three.js** and **GSAP** over the **Great 3D Topographical Map of Iraq** (Tigris, Euphrates, Mountain ranges, and Shatt al-Arab).
* Explores the **6 Continents**, **40 articulated 3D agent characters**, and interactive live flight simulation of multi-agent tasks in real time.

### 6. Integrity Verification
Ensure your installation meets 100% architectural and security standards:
```bash
# Full test suite (1729 strict assertions)
node eval/run.js

# Benchmark speed and memory footprint
node run_benchmark_suite.js
```

## ⚡ Seven Governing Commands · الأوامر الحاكمة السبعة

Available natively per platform (e.g. Claude `/majlis:start`, Codex `/prompts:majlis-start`, Gemini CLI `/majlis:start`, or natural language: *"run majlis deliberate"*):

| Command | Action | Enforced Gate |
|---|---|---|
| `/majlis:start` | Initializes guided governance, `.majlis/` project constitution, and roadmap. | Mandatory setup |
| `/majlis:plan <n>` | Decomposes phase into atomic waves with runnable verification contracts. | No-verify plans rejected |
| `/majlis:build` | Executes parallel waves via specialized council agents with atomic commits. | Forbidden globs & test checks |
| `/majlis:review` | Independent 2–4 reviewer panel applying anti-sycophancy rubrics. | Blocker bounces (≤3 cycles) |
| `/majlis:deliberate` | **NEW:** Closed Adversarial War-Room (MARP-V1) for high-stakes decisions. | Mandatory fatal flaw extraction |
| `/majlis:security` | Offensive security audit: TruffleHog secrets → Nuclei → OWASP ZAP. | **SECURITY: PASS** mandatory |
| `/majlis:status` | Live dashboard showing milestone progress and exact next action. | Read-only |

### 🚨 The Signature Red Gate
Before any release is signed off, the offensive security pipeline executes:
1. **Secrets Sweep:** TruffleHog checks git tree and environment files.
2. **Vulnerability Audit:** Nuclei templates scan configuration exposure.
3. **API Defense:** OWASP ZAP tests dynamic endpoint protection.
4. **Binary Verdict:** A single security failure halts the entire release.
